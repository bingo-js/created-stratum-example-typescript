# created-stratum-example-typescript

Example repository created from create-stratum-example's `--preset typescript`. 💕

## Development

Requires Node.js LTS.
After [forking the repo from GitHub](https://help.github.com/articles/fork-a-repo):

```shell
git clone https://github.com/(your-name-here)/created-stratum-example-typescript
cd created-stratum-example-typescript
npm install
```

### Building

```shell
npm run build
```

Builds source files from `src/` to output in `lib/` using [TypeScript](https://www.typescriptlang.org).

### Formatting

```shell
npm run format
```

Formats files with [Prettier](https://prettier.io).
